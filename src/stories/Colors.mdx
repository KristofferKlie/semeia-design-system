## Regras de Uso

### Usar Verde (#3D8B40) em:
- Botões primários (CTAs)
- Links ativos na navegação
- Ícones e containers de ícones
- Bordas hover de cards
- Números de estatísticas (usar #4ade80 — tom mais claro)
- Divisores decorativos (gradiente #3D8B40 → #4ade80)
- Focus ring

### NÃO usar:
- Fundo verde em seções inteiras — proibido (`lp-bg-brand` removido)
- Laranja/dourado (#E8941A) em elementos principais — apenas accent especial
- Fundos brancos ou claros — site é 100% dark mode
- Azul como cor primária — é secondary/info apenas

## Gradientes Oficiais

```css
/* Text gradient — verde */
linear-gradient(135deg, #5a9a5c 0%, #3d8b40 50%, #2e7d32 100%)

/* Hero text highlight */
linear-gradient(90deg, #ffffff 0%, #86efac 50%, #4ade80 100%)

/* Hero radial glow */
radial-gradient(ellipse at center, rgba(61, 139, 64, 0.15) 0%, transparent 70%)

/* Divider brand */
linear-gradient(90deg, #3D8B40, #4ade80)

/* Divider accent */
linear-gradient(90deg, #E8941A, #fbbf24)
```

## Uso no Código

```tsx
// Botão primário
<button className="lp-btn lp-btn-lg">Conheça nossas soluções</button>

// Badge
<span className="lp-badge">Inovação em Educação</span>

// Card
<div className="lp-card">...</div>

// Texto com gradiente
<span className="lp-text-gradient">educação com IA</span>

// Stat number
<p className="lp-stat-number">30+</p>

// Via Tailwind direto
<div className="bg-[#3D8B40] text-white">Primary button</div>
<div className="bg-[#171717] border border-white/10">Card</div>
<p className="text-[#A3A3A3]">Texto secundário</p>
<p className="text-[#4ade80] font-bold">Número destaque</p>
```
